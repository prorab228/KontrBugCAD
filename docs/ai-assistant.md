# ИИ-ассистент КонтрCAD

Встроенный чат, который управляет 3D-сценой: создаёт примитивы, эскизы,
выдавливания и булевы операции через те же MCP-инструменты, что доступны
внешним клиентам. Работает в **веб-версии** и в **десктопном приложении**.

## Быстрый старт

1. Откройте вкладку **AI** в правой панели (над вкладками «Библиотека», «Свойства»…).
2. Нажмите на пилюлю модели внизу и выберите **«Настроить модели и ключи…»**
   (или ⚙ → «ИИ-ассистент» → «Модели и ключи»).
3. Выберите провайдера, вставьте ключ и нажмите **«Сохранить»**.
   Ключ сразу проверяется, а список моделей подтягивается из API провайдера.
4. Выберите модель в том же меню и напишите запрос, например:
   _«Создай куб 40×40×40 и просверли отверстие Ø24»_.

## Провайдеры

| Провайдер | Веб | Десктоп | Примечание |
|---|---|---|---|
| **GigaChat** | — | ✅ | OAuth и российские сертификаты — через встроенный прокси |
| **DeepSeek** | ✅ | ✅ | OpenAI-совместимый |
| **OpenRouter** | ✅ | ✅ | Сотни моделей, в том числе бесплатные |
| **OpenAI** | ✅ | ✅ | |
| **Google Gemini** | ✅ | ✅ | через OpenAI-совместимый endpoint |
| **Groq** | ✅ | ✅ | быстрый инференс |
| **Mistral** | ✅ | ✅ | |
| **Ollama** | ⚠️ | ✅ | без ключа; в браузере нужен `OLLAMA_ORIGINS=*` |
| **Свой API** | ✅ | ✅ | любой OpenAI-совместимый сервер |
| **API КонтрCAD** | — | — | скоро: доступ по подписке |

> **Особенность GigaChat:** его API принимает только один вызов инструмента за
> ход (старый формат `functions`, современный `tools` он молча игнорирует).
> Поэтому ассистент даёт GigaChat только базовые инструменты и просит
> объединять операции через `batch` с аргументами в `arguments_json`.
> Для сложных сборок всё равно лучше DeepSeek или OpenAI: они умеют несколько
> вызовов в одном ответе.

Список моделей **не хранится в коде**: он запрашивается у провайдера
(`GET /models`) при запуске, после ввода ключа и по кнопке «Обновить список».
Кэш — 6 часов. Поэтому новые модели появляются сами, без обновления приложения.

Подписи моделей генерируются из их id: `deepseek-v4-pro` → **DeepSeek V4 Pro**,
`qwen2.5-coder:7b` → **Qwen2.5 Coder 7B**. Если модель не подходит под правила,
её можно добавить вручную и назвать как удобно.

## Ключи

| | Десктоп | Веб |
|---|---|---|
| Где хранится | `safeStorage` (DPAPI / Keychain), файл `%APPDATA%\kontrbugcad\ai\ai-keys.json` | `localStorage` браузера |
| Виден ли рендереру | нет — только «сохранён / нет» | да (ограничение браузера) |
| Шифрование | системное | нет |

В веб-версии ключ лежит в браузере, поэтому не используйте его на чужих
компьютерах и не устанавливайте сомнительные расширения. Удалить ключ можно
кнопкой «Удалить» в настройках ИИ.

Ключи уходят только напрямую провайдеру (в десктопе — из main-процесса,
в вебе — из браузера). Через серверы КонтрCAD они не проходят.

## Параметры

- **Температура** — 0…2, по умолчанию 0.3 (для CAD-задач лучше низкая).
- **Макс. токенов** — 0 означает «без ограничения».
- **Стриминг** — ответ печатается по мере генерации. У GigaChat куски крупнее
  (по предложениям), у OpenAI-совместимых — мельче.

## Вложения

- **Изображения** — кнопка 📎, вставка из буфера или drag&drop. До 5 файлов,
  до 6 МБ каждый; большие картинки сжимаются до 1400 px по длинной стороне.
  Картинка уходит провайдеру в стандартном формате vision — поддерживает ли её
  конкретная модель, решает API (при отказе покажем его ошибку).
  Исключение — GigaChat: его адаптер пока не умеет загружать файлы.
- **Текстовые файлы** — txt, md, csv, json, код, dxf и подобные, до 2 МБ.
  Содержимое вставляется в сообщение как текст.

## Кнопки композера

- **+** — новый диалог (история очищается).
- **📎** — прикрепить файл.
- **Пилюля модели** — выбор модели и переход в настройки.
- **Стрелка** — отправить; во время ответа превращается в «Стоп» и обрывает
  соединение с провайдером.

Пока ассистент ждёт модель или выполняет инструменты, в чате видны три
пульсирующие точки. Это единственная индикация: пошаговые сообщения
(«Выполняю: create_primitive…») намеренно убраны.

## Свой OpenAI-совместимый сервер

В настройках выберите «Свой OpenAI-совместимый API» и укажите **полный** адрес
запроса, например:

```
http://localhost:1234/v1/chat/completions
```

Список моделей берётся из `.../v1/models`. Подходит vLLM, LiteLLM, LM Studio,
llama.cpp server, корпоративный шлюз. В веб-версии сервер должен разрешать CORS.

## Если что-то не работает

| Симптом | Причина и решение |
|---|---|
| Список моделей пуст | нет ключа, провайдер недоступен или не ответил — введите ключ и нажмите «Обновить список» |
| «Браузер блокирует запрос (CORS)» | провайдер не разрешает запросы из браузера — откройте десктопную версию |
| GigaChat: ошибка сертификата | не нашли российские корневые сертификаты — переустановите приложение (они входят в поставку) |
| HTTP 401 / 403 | неверный или просроченный ключ |
| HTTP 429 | лимит запросов у провайдера — подождите или смените модель |
| HTTP 402 | закончились средства на счёте провайдера |
| Ollama: соединение отклонено | не запущен `ollama serve` |
| Модель не вызывает инструменты | выберите модель с поддержкой function calling |
| Картинка не принимается | модель без vision или провайдер не поддерживает изображения — текст ошибки придёт от API |

Протокол — OpenAI Chat Completions. Всё, что говорит на этом языке,
подключается без изменений кода; GigaChat приводится адаптером к тому же виду.

## API КонтрCAD (скоро)

Для платной версии появится шлюз, совместимый с OpenAI:

```
POST https://www.kontrcad.ru/api/ai/v1/chat/completions
GET  https://www.kontrcad.ru/api/ai/v1/models
Authorization: Bearer <токен аккаунта>
```

Ключи провайдеров будут храниться на сервере, клиенту останется вход в аккаунт.
В настройках провайдер уже виден с пометкой «скоро».
